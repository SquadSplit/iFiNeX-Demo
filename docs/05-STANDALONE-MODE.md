# 05 · Standalone mode (no server at all)

1. Publish the website without `ifinex-config.json` (or open `web/start.html` locally through any static server).
2. On the first screen open the **📱 Standalone** tab → **Use standalone**.
3. Data is stored in this browser (IndexedDB). It is single user and not shared with other devices.
4. **Back up:** Settings → Backup → export file (or Google Drive backup if you configured it). Clearing browser data deletes standalone data — export regularly.
