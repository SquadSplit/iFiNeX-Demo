Simulated Google. The app code is the real one (data stays on the phone; Google sign-in; nightly backup; restore). Fake: Google's page (the code is approved by itself after a few seconds), the Drive list below (it lives in this page, so it survives a “new phone”) and Android's midnight timer (use the 🌙 button).

Try it — 6 steps

1. First start shows “Welcome”. Press Continue with Google. Wait for the code to be accepted (about 8 s). The account has no backup yet, so press Start fresh and type a name.
2. Add some data: open Bill Tracker → ➕ Add and save two or three expenses.
3. Press 🌙 Simulate 12:00 AM below. The nightly backup runs: a file appears in “Your Google Drive”. Press it again: nothing new — data did not change.
4. Press 🗑️ New phone (reinstall). The phone is wiped; Google's Drive is kept.
5. On the welcome screen press Continue with Google. It finds Latest backup found with its date and number of records. Press Restore this latest backup — your expenses are back. (Or choose Start fresh.)
6. Any time later: ☰ → Backup & Restore → Restore my latest Google backup.
